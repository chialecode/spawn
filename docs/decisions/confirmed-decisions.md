# SPAWN 已确认架构与治理决策总表（Confirmed Decisions）

本文件汇总 SPAWN 项目已完成技术验证并正式锁定的 **35 项核心决策（`D-01` ~ `D-35`）** 与 **6 项可逆工程默认策略（`A-01` ~ `A-06`）**。后续编码实现必须严格遵照本表执行，禁止在未立项新 ADR 或未同步本表的情况下引入偏离方案。

## 2. 可逆工程默认策略（`A-01` ~ `A-06`）

以下工程参数设定为经过权衡的推荐默认值，可在后续里程碑实机基准测试中通过配置项微调而无需重构顶层架构：

| 编号 | 工程参数 | 推荐默认值 | 可调范围与调整触发条件 |
| :--- | :--- | :--- | :--- |
| `A-01` | `FastCDC` 分块窗口参数 | 最小 `256 KiB`、均值 `1 MiB`、最大 `4 MiB`，`Zstd` 压缩级别 `Level 3` | 若超大型存档（`>2 GiB` SQLite 单文件）去重率偏低，可在游戏级策略下调均值至 `512 KiB`。 |
| `A-02` | `SPPK` 云同步封装包体积上限 | 单包目标上限 `32 MiB`，历史血缘保留最近 `64` 代 `ParentSnapshotId` | 针对高丢包弱网 WebDAV 后端，支持在设置面板将封装阈值调低至 `16 MiB`。 |
| `A-03` | 存档监控防撕裂静默等待窗口 | 文件停止写入后等待 `2500 ms` 再执行双元数据向量快照提取 | 针对极少数每秒持续刷写日志型存档的游戏，超时 `15 s` 后自动切换 `AlphaVSS` 卷影快照通道。 |
| `A-04` | 反作弊退出静默冷却时长 | 反作弊伴生进程彻底消失后固定冷却 `15 s` | 只允许在设置中向上延长（如 `30 s`），禁止缩短至 `15 s` 以下以确保安全冗余。 |
| `A-05` | 成就监听去抖与前台微轮询周期 | `FileSystemWatcher` 去抖合并窗口 `120 ms`，前台运行态游戏元数据兜底轮询周期 `500 ms` | 低功耗掌机电池模式下可将兜底微轮询放宽至 `1000 ms`。 |
| `A-06` | WOF 透明压缩采样与熵值跳过阈值 | 首中尾 `3 × 64 KiB` 采样，香农熵 $H > 7.85\text{ bits/byte}$ 自动跳过，默认算法 `XPRESS8K` | 归档冷存储模式可手动显式指定更高压缩率的 `LZX` 算法。 |
