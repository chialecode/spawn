# SPAWN UI 与交互设计规范

本规范约束 `Spawn.Host.exe`（沉浸式三栏桌面主界面、系统托盘与后续 `Nodify` 蓝图画布）及 `Spawn.OverlayHost.exe`（免注入游戏内实时成就跳杯弹窗与战术交互面板）的窗口布局、视觉色板、整洁交互守则、UI 虚拟化、动效音频及多屏 DPI 行为。跨模块业务操作流详见 [交互与工作流设计](../design/interaction-and-workflows.md)。

## 1. 沉浸式无边框三栏布局与清透双主题视觉体系

### 1.1 窗口布局与响应式断点（`WindowChrome` 通顶三栏）

`Spawn.Host.exe` 取消系统原生厚重标题栏，采用 `WindowChrome` 沉浸式无边框窗口，**最左图标栏、上下文侧栏与右侧主面板三栏全部通顶（`top = 0px`）**：

| 窗口宽度区间 | 第一栏：窄图标栏 | 第二栏：上下文侧栏 | 第三栏：右侧主面板 |
| :--- | :---: | :---: | :--- |
| `>= 1000 DIPs`（常规桌面宽屏） | 固定 `52px` | 固定 `264px`（右侧 `1px` 分隔线） | 占据剩余全部宽度（顶部固定栏 + 独立视口工作区） |
| `< 1000 DIPs`（紧凑窄窗） | 固定 `52px` | 自动折叠隐藏（可通过顶栏侧栏开关呼出抽屉或页内切换） | 占据剩余全部宽度，顶栏极简无截断，内容与控件自适应换行 |

- **自定义标题栏交互与窗口控制按钮**：右上角自绘最小化（`─`）、最大化/还原（`□`）与关闭（`×`，悬停红底 `#E81123` 白字）三枚控制按钮，覆盖于主面板固定顶部栏最右端；主面板顶部栏右侧预留充足安全退让间距。三栏顶部高度对齐区空白处均支持左键按住拖拽移动窗口、双击最大化/还原，并完整支持 Windows 11 贴靠布局与多显示器 `PerMonitorV2` 无缝缩放。
- **第一栏：最左侧窄图标切换栏（宽 `52px`）**：
  - 顶部居中展示沉稳醒目的纯品牌字标 **`S`**（仅作视觉标志，不作按钮）；
  - 紧挨字标下方垂直排列 `40x40px` 圆角方块（`CornerRadius="10"`）线性矢量图标导航项（描边粗细一致，常规 `1.6px`、选中 `2.0px`，悬停带中文 `ToolTip` 与无障碍名称）；
  - **严守“不显示未落地空壳入口”铁律**：仅挂载当前里程碑已完整交付的业务视图——当前包含 **① 游戏库（`Spawn`）**（有游戏正在运行时，图标右上角展示一颗 `8px` 翡翠绿 `#10B981` 状态圆点）、**② 成就中心（`Achievements`）**（跨游戏全收集进度墙、最近解锁时间线与弹窗预览）、**③ 存档时间机器（`Saves`）**（分支树工作台、跨游戏存档总览与自建云同步状态点）与 **④ 修改器（`Trainers`）**（`1.6px` / 选中 `2.0px` 线性滑块图标，存在活跃修改器会话时右上角同步点亮一颗 `8px` 翡翠绿 `#10B981` 状态圆点）；后续里程碑交付 `Nexus`、`Workflow` 时按同一规格挂载；
  - 底部固定：**安全与运行通道状态徽标**（悬浮查看 `Anti-Cheat Guard` 等级/冷却状态与 `spawn` / `spawn-dev` 数据通道）及 **设置（⚙ 齿轮线性图标）**。
- **第二栏：二级上下文侧栏（宽 `264px`）**：
  - 固定不随右侧详情页滚动，承载当前一级模块下“看什么”的结构化选择：
    - **游戏库视图**：顶部 `18px SemiBold` 标题 `游戏库` + 右侧轻量扫描/刷新图标按钮；下方支持按来源折叠分组（`> 全部游戏`、`> GOG`、`> Steamrip`、`> Steam 本地`）与紧凑条目行——每行展示圆角小图标/封面（优先取自离线 `webcache.zip` 或本地媒体缓存）、单行游戏名、右侧次要小字来源标签；正在运行的游戏带绿色外圈并置顶排列，选中项采用浅强调色胶囊底高亮。
    - **成就中心视图**：顶部 `18px SemiBold` 标题 `成就`；上方固定“最近解锁总览”入口，下方列出已入库各游戏的紧凑进度条与解锁比（如 `LIMBO · 0/13`、`Vampire Survivors · 0/220`）。
    - **存档视图**：顶部 `18px SemiBold` 标题 `存档` + 右侧轻量刷新图标按钮；上方固定 **`全部存档总览`** 入口与带中文输入法（IME）组合态 `Enter` 防误触保护的检索框，下方按最近快照时间与分支数排序展示全部游戏，单行展示紧凑封面、游戏名、当前活跃分支胶囊与快照计数。
    - **修改器视图**：顶部 `18px SemiBold` 标题 `修改器` + 右侧轻量刷新图标按钮；上方固定 **`全部修改器总览`** 入口与带中文输入法（IME）组合态 `Enter` 防误触保护的检索框，下方按优先级排序展示游戏列表（运行中修改器 → 已就绪已绑定修改器 → 可用单机 `Tier 0` / 混合单机 → 受保护屏蔽游戏），单行展示紧凑封面、游戏名与修改器运行/绑定状态标签。
    - **设置视图**：顶部左侧带返回箭头 `←` 与标题 `设置`（点击返回进入设置前的视图），下方列出七大分组（`常规与游戏库`、`成就与 Steam API`、`弹窗外观与音效`、`存档与云同步`、`修改器与安全沙箱`、`外观主题`、`关于与版本`）。
- **第三栏：右侧主面板**：
  - **固定顶部栏（不随内容滚动，底部 `1px` 细分隔线）**：左侧显示当前视图或选中游戏标题（`18px SemiBold`，窄窗时前置侧栏折叠开关）；右侧仅保留自定义窗口控制按钮（最小化 / 最大化 / 关闭），**不放置顶部胶囊导入/扫描栏**以保持极简通透。多目录游戏库扫描配置、单游戏目录/EXE 手动导入与“立即扫描游戏库”按钮统一收口至 **`设置 → 常规与游戏库`**（空库页面提供直达该设置页的按钮，且窗口任意区域仍支持文件/文件夹拖放导入）。
  - **全局反作弊冷却横幅**：当 `AntiCheatGuard` 处于非 `IdleSafe` 状态（受保护网游运行中、残影监控或 15 秒余温冷却）时，顶栏下方常驻高辨识度等宽字体倒计时横幅，同步置灰修改器启动与热键代理控件。
  - **存档时间机器主视图（`全部存档总览` 与同步单游戏分支树工作台）**：
    - 选中 `全部存档总览` 时，展示全库存档去重统计摘要（总快照数、总分支数、FastCDC+Zstd 去重节省体积与云同步状态）、一键 CAS 垃圾回收及 `Recycling` 虚拟化游戏存档汇总列表；
    - 选中侧栏任意游戏时，复用与 **`游戏库 → 游戏详情 → 存档`** 同一共享分支树工作台（`SaveWorkbenchControl`）：顶部显示活跃分支切换条、唯一主按钮 **`立即备份`**、云同步快捷按钮与 `⋯` 菜单（导入旧版启动前快照、刷新 Ludusavi 规则、打开本地存档目录）；主体采用纯原生 WPF `DrawingContext` 自绘 Git 式彩色多轨分支树（`SaveGraphCellControl`，零 WebView2，每轨采用高对比度 6 色语义色板 `#1677FF` / `#10B981` / `#8B5CF6` / `#F59E0B` / `#EC4899` / `#06B6D4`，支持从任意历史节点分叉命名分支、切换分支、钉住/备注、安全回滚与 SPPK 异地分叉决策向导）。
  - **修改器主视图（`全部修改器总览` 与同步单游戏工作台）**：
    - 选中 `全部修改器总览` 时，主面板依次展示全库修改器统计摘要条、安全沙箱目录与 Defender 快捷栏、运行中修改器活跃状态横幅，以及启用 `VirtualizingPanel.VirtualizationMode="Recycling"` 的已纳管修改器列表（支持一键启动/停止、打开沙箱、校验 SHA-256、VirusTotal 哈希查看与经 `PlacementTarget.Tag` 桥接的 `⋯` 菜单移除；无修改器时展示温和空状态引导）；
    - 选中侧栏任意游戏时，直接复用与 **`游戏库 → 游戏详情 → 修改器`** 同一共享工作台模板（支持窗口拖放本地修改器导入、双向选中同步与 `ITrainerRuntimeService.StateChanged` 实时运行态联动）。
  - **游戏详情工作台四子页签与高性能虚拟化**：
    - 头部安全等级徽标严格按 `AntiCheatTier` 语义着色：`Tier 0` 翡翠绿 `#10B981`、`Tier 1` 琥珀 `#F59E0B`、`Tier 2/3` 警戒红 `#DC2626`，混合单机启用受控离线放行时附加 **`离线无 AC 就绪`** 小徽标；
    - 头部下方提供清爽底线四子标签切换：**`成就 (已解锁/总数)`** | **`存档`** | **`游戏数据`** | **`修改器`**（头部 `⋯` 菜单同步提供 `管理 / 清理游戏数据` 与 `打开修改器` 快捷跳转）；
    - **`成就` 子页签**：列表容器固定于受限 `*` 行高内并强制启用 `VirtualizingPanel.IsVirtualizing="True"`、`VirtualizationMode="Recycling"` 与像素级平滑滚动（`ScrollUnit="Pixel"`），即便面对 220+ 项带高清图标成就的大型肉鸽/RPG 游戏也能零卡顿秒开；
    - **`存档` 子页签**：复用 `SaveWorkbenchControl`，展示当前游戏的 Ludusavi `[save]`/`[config]` 探测路径、分支切换胶囊、纯原生 WPF `DrawingContext` Git 式彩色分支历史树（任意节点分叉、回滚、钉住、备注）、运行中游戏防误覆盖保护以及 32MB SPPK 云同步状态与分叉向导；
    - **`游戏数据` 子页签**：按 `存档数据`、`离线成就文件`、`配置与日志`、`注册表项` 四大类别展示由 PCGamingWiki、Unity/Unreal 引擎目录推断与全流派离线模拟器定位出的路径/键名、来源小字徽标、存在状态与占用字节数；每行提供 `打开目录` / `复制路径`，顶部工具条提供 `刷新 / 同步 PCGamingWiki`、唯一主按钮 **`清理选中数据`**（附勾选框 `同时重置 SPAWN 成就进度与游玩时长`）及可逆回收站 **`恢复上次清理`** 按钮；
    - **`修改器` 子页签**：遵循四态安全视觉——受保护联网游戏（`Tier 1/3` 或无单人模式 `Tier 2`）物理不渲染下载/启动控件、仅渲染安全围栏说明卡；混合单机渲染可展开离线校验面板（实时 AC 进程/驱动清零状态 + 显式确认）；`vgk.sys` 空闲驻留展示可折叠橙色警示条；允许态下以唯一主按钮三态状态机（未绑定 `匹配修改器` + `导入本地文件`；就绪 `启动修改器` + 经 `PlacementTarget.Tag` 桥接的 `⋯` 菜单含重新匹配/导入覆盖/打开沙箱/校验 SHA-256/重置开关显示/VirusTotal 哈希查看/红字移除；运行中翡翠绿 `运行中 · 停止修改器` + `显示 / 隐藏原窗口`）配合回收虚拟化热键列表（含自由托管手动热键录入）与启动前轻量存档快照一键回滚列表（游戏运行中禁用）。
- **系统托盘与双通道标识（`--background` / `--quit-for-update`）**：
  - 支持 `--background` 参数后台静默启动至 Windows 系统托盘（不弹主窗口、不抢前台焦点；若交互会话托盘创建失败则安全回退展示主窗口，并监听 `TaskbarCreated` 在资源管理器重启后自动恢复托盘图标），单击/双击托盘图标或点击原生右键菜单 `打开主界面` 唤醒聚焦，点击 `退出 SPAWN` 完全退出；已有实例运行中再次传入 `--background` 保持静默不弹窗；
  - 开发通道（`dev` / `source`）自动采用带醒目琥珀色 **`DEV`** 角标的应用与托盘图标，与正式版物理及视觉双重区分；
  - **应用图标统一规格**（1024 单位画布，矢量正本 `assets/icon.svg` / `assets/icon-dev.svg`）：纯色无渐变/描边/阴影的深灰圆角方底（`48..976`、`rx=200`、`#3C4043`）+ 白色 `#FFFFFF` 几何字母 `S`（字高 `250..780`、笔画 `110`、端点圆角 `28`）；开发版在右下叠加纯色琥珀角标（`560,800` 起 `400x160`、`rx=52`、`#F3A115`）与 `#202124` 几何 `DEV` 字形。`scripts/generate_icons.py` 栅格化产物（`icon(-dev).png|ico`）与托盘兜底 `BrandIconGeometry`（SkiaSharp）共用同一几何与色值，由 `BrandIconParityGateTests` 守护一致；收到安装器 `--quit-for-update` 握手指令时，静默优雅关闭托盘、`OverlayHost` 与主进程（绝不误杀运行中的玩家游戏）。

| 语义角色 | 清透浅色主题（Light Default） | 极客深色主题（Dark Mode，设置一键切换） | 适用范围与对比度约束 |

| **轻量占位 / 次级提示块** | `#F2F3F5` | `#232730` | 缺省封面占位、空状态温和提示条、未满进度槽底 |
| **分隔细线 / 控件描边** | `#EAEAEA` / `#DCDCDC` | `#2A2F3A` / `#363C49` | 栏间 `1px` 竖线、顶栏底线、列表行分隔线、胶囊外框 |
| **条目悬停态背景** | `#EBEBEB` | `#262B35` | 图标栏按钮、侧栏行、次要按钮与菜单项悬停 |

### 1.3 整洁交互原则与字体排版

1. **单主按钮与浮动 `⋯` 菜单守则**：
   - 每个界面区域最多放置 **1 个强调色主按钮**（例如游戏详情头部仅突出 `启动游戏`，运行中切换为 `运行中 · 停止`；`游戏数据` 工具栏仅突出 `清理选中数据`）。
   - 其余低频与管理动作一律收进主按钮右侧的 **`⋯` 浮动弹出菜单**（圆角浮层 + 柔和投影，右对齐展开于按钮下方，点击外部或按 `Esc` 即关，绝不在页面内铺开一排文字按钮推挤内容；危险动作如 `从游戏库移除` 置于分隔线下方并用红色文字标识）。
2. **字体与等宽数字对齐**：
   - 界面中文与英文混排采用 `Segoe UI Variable Text` / `Segoe UI` + `Microsoft YaHei UI`（字阶：页面与侧栏主标题 `18px SemiBold`、游戏详情大标题 `22px SemiBold`、正文与条目 `14px`、次要元信息与来源标签 `12px`）；
   - 三态游玩时长（`HH:MM:SS`）、文件占用大小、解锁时间戳、全球达成率百分比、版本号与提交短哈希统一使用等宽字体（`Cascadia Mono` / `Consolas`）并启用 `Tabular` 等宽数字特性，动态刷新零抖动。

## 2. `Spawn.OverlayHost` 零抢焦点实时成就跳杯弹窗规范

`Spawn.OverlayHost.exe` 作为物理隔离的独立轻量 `WinExe` 进程直接叠加于游戏画面上方，严守“零注入、零抢焦点、零打扰测试”三大红线：

1. **Win32 穿透置顶窗口样式硬约束**：
   - 窗口在 `SourceInitialized` 阶段通过 `GetWindowLongPtr` / `SetWindowLongPtr` 强制施加扩展样式 **`WS_EX_TOPMOST | WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`**，并以 `ShowWindow(..., SW_SHOWNOACTIVATE)` 呈现。
   - **绝对不抢夺前台键盘鼠标焦点**、绝不导致全屏或无边框窗口化游戏最小化切出桌面、不在任务栏或 `Alt + Tab` 视图中产生多余窗口图标，透明区域鼠标点击 100% 物理穿透至底层游戏。
   - 在已执行本机瞬态自签名的安装环境下自动运行于 `ZBID_UIACCESS` 置顶频段；未签名开发/便携环境下零报错平滑回退常规 `HWND_TOPMOST`。
2. **多成就优雅排队与三套首发高颜值主题卡片**：
   - 通过 `Spawn.Core` 的 `NamedPipeJsonRpc` 接收来自 `Spawn.Host` 的 `OverlayToastRequest`；同一瞬间连续解锁多项成就时进入 FIFO 播放队列，按缓动曲线依次滑入、悬停展示、丝滑滑出，无弹窗期间停止动画计时器保持 `0% GPU` 静默。
   - 首次扫描游戏存量已解锁记录默认静默入库（`NotifiedPopup = 1`），绝不在导入老存档时刷屏轰炸。
   - **三套高辨识度首发主题**（支持屏幕四角定位切换）：
     - **`Steam 经典`**：深灰渐变底板 + 左侧 `56x56` 高清成就彩图 + 右侧解锁标题与中文条件微光扫掠；
     - **`PS5 奖杯`**：流线胶囊卡片，按全球稀有度自动映射铜/银/金奖杯光泽；当解锁本游戏最后一项成就达成 **100% 全收集** 时，队列自动追加弹出专属 **「白金奖杯 · 全成就达成」** 庆典流光卡片；
     - **`Xbox 稀有紫钻`**：圆角胶囊展开动效，全球达成率 `< 10.0%` 的稀有成就自动触发紫钻/金钻徽章光效与稀有度百分比展示。
3. **无外部依赖内存合成音效与静音铁律**：
   - 内置轻量 PCM/WAV 和弦合成器（区分普通清脆双音和弦、稀有紫钻泛音和弦与白金庆典琶音），通过 `NAudio.Wasapi` 共享模式（`AudioClientShareMode.Shared`）按用户设定的音量滑块（`0% ~ 100%`）混音播放，无需携带外部音频资产文件。
   - 当音量设为 `0%`、请求显式标记静音或处于自动化门禁/单元测试环境时，**100% 物理跳过音频设备初始化与发声**。
4. **`Alt + Z` 战术交互面板扩展契约（M4 联动）**：
   - 后续挂载游戏内交互面板时，热键监听仅允许使用系统 `RegisterHotKey`（严禁 `WH_KEYBOARD_LL` 低级钩子），呼出时按状态机对称移除穿透位、接管焦点并以 `ClipCursor` 锁定光标边界，关闭时精确还原游戏窗口焦点与原锁鼠矩形。

## 3. `miroiu/nodify` 类 UE Blueprint 双画布视觉规范（M6 蓝图工作台）

面向后续可视化自动化与排班阶段，节点画布统一采用 `miroiu/nodify` 构建并遵循 Unreal Engine Blueprint 视觉语义：

1. **无限网格与 GPU 矩阵缩放**：双级网格背景配合 `MatrixTransform` 视口缩放（`0.15x ~ 2.50x`），保证千级节点拖拽平移稳跑 `60+ FPS`。
2. **双引脚（`ExecPin` vs `DataPin<T>`）标准色板**：
   - **执行流引脚（`ExecPin`）**：五边形楔形箭头 + 纯白高亮连线（`2.5px`，运行态叠加脉冲流光），遵循“输入多对一、输出一对一”；
   - **强类型数据流引脚（`DataPin<T>`）**：圆形引脚，按类型严格区分 `Boolean`（绯红 `#DC2626`）、`Int32/Double`（翠绿 `#22C55E`）、`String`（洋红 `#EC4899`）、`Point/Rect ROI`（琥珀金 `#EAB308`）、`ImageMat`（湖蓝 `#0EA5E9`）与 `WindowHandle`（紫罗兰 `#8B5CF6`）。

## 4. 多屏异构 PerMonitorV2 DPI、输入法防误触与诚实状态反馈

1. **多屏异构 `PerMonitorV2` DPI 一致性**：
   - `Spawn.Host` 与 `Spawn.OverlayHost` 的应用清单（`app.manifest`）均显式声明 `PerMonitorV2` DPI 感知。桌面三栏与弹窗卡片统一按 96 DPI 设备无关像素（DIPs）排版；`OverlayHost` 定位屏幕四角工作区坐标时通过目标显示器真实 DPI 缩放因子精确换算，跨 4K（200%）与 1080p（100%）显示器零偏移、零模糊。
2. **中文输入法（IME）组合态防误触**：
   - 设置页手动导入路径框、修改器侧栏检索框、修改器检索覆盖框、成就搜索框等文本输入控件在中文输入法拼音候选组合态（IME Composition）下按 `Enter` 时，仅完成选词上屏，严禁误触发导入扫描或表单提交。
3. **诚实状态与防剧透反馈**：
   - 未选游戏空状态、离线无网络降级、Steam Web API Key 来源脱敏展示（如识别本地开发密钥或本机 DPAPI 存储并掩码为 `4D3F****************************68CD`）、`gbe_fork` 备份还原结果、游戏数据可逆清理/恢复状态及 `15s` 反作弊冷却倒计时均以清晰中文如实呈现；
   - 未解锁且标记为 `IsHidden` 的隐藏成就默认隐藏达成条件，展示 `隐藏成就 · 点击展开查看条件`，支持单条点击揭晓或通过详情页开关全局显示剧透。
